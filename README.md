# HBuilderx语言服务

[![License](https://img.shields.io/:license-Apache%202-blue.svg)](https://www.apache.org/licenses/LICENSE-2.0.txt)

`hbuilderx-language-services`是一个为[HBuilderX](https://www.dcloud.io/hbuilderx.html)提供语言服务的插件，基于[TypeScript](https://www.typescriptlang.org/)和[VSCode](https://code.visualstudio.com/)的语言服务实现。

现将其进行vscode的适配, 并开源
